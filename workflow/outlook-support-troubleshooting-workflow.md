# Outlook Support Troubleshooting Workflow

## Purpose

This workflow outlines a basic Service Desk process for troubleshooting Outlook and Microsoft 365 mailbox issues.

It is designed for common first-line support scenarios such as sign-in issues, shared mailbox access, email forwarding, automatic replies, mailbox storage, and Outlook sync problems.

## 1. Confirm the User and Issue

Before making changes, confirm:

- Affected user
- Affected mailbox
- Exact issue reported
- Whether the issue affects Outlook web, desktop Outlook, or mobile Outlook
- When the issue started
- Whether any error message appears

## 2. Check Microsoft 365 Account Status

In Microsoft 365 Admin Centre, review:

- User account exists
- Sign-in is not blocked
- Microsoft 365 licence is assigned
- Mailbox settings are available
- User details are correct

## 3. Check Outlook Access

Test or confirm access using:

- Outlook on the web
- Correct user account
- Browser refresh or private window
- Alternative browser if needed

If Outlook on the web works but desktop Outlook does not, the issue may be related to Outlook desktop, cached data, or the local profile.

## 4. Review Mailbox Settings

From the user Mail tab, review:

- Mailbox permissions
- Email apps
- Email forwarding
- Automatic replies
- Mailbox storage

These settings help identify access, delivery, sync, and configuration issues.

## 5. Shared Mailbox Checks

For shared mailbox issues:

- Confirm the shared mailbox exists
- Review shared mailbox members
- Confirm the user has access
- Use Outlook on the web
- Use Open another mailbox
- Confirm whether the mailbox opens successfully

If permissions are correct but the issue continues, allow time for changes to apply or escalate if needed.

## 6. Email Forwarding Checks

For suspected forwarding issues:

- Open Manage email forwarding
- Confirm whether forwarding is enabled
- Check the forwarding address
- Confirm whether the address is internal or external
- Disable forwarding if it is not required
- Escalate external forwarding requests if blocked by policy

Unexpected forwarding should be treated carefully because it may create a security risk.

## 7. Automatic Replies Checks

For out-of-office issues:

- Open Manage automatic replies
- Confirm whether replies are turned on
- Check the internal reply message
- Check whether external replies are enabled if required
- Update or disable replies as needed
- Ask the user to test again

## 8. Mailbox Storage or Sync Checks

For mailbox storage or sync issues:

- Check mailbox storage
- Confirm Outlook on the web access
- Review email apps
- Confirm licence assignment
- Ask whether the issue affects one device or all devices
- Restart Outlook if using desktop Outlook
- Escalate if Outlook web works but desktop Outlook continues to fail

## 9. Document the Ticket

Each support ticket should include:

- User/requester
- Issue summary
- Priority
- Troubleshooting steps taken
- Findings
- Resolution
- Any escalation notes

## 10. Escalation

Escalate if:

- The issue continues after basic account and mailbox checks
- Permissions are correct but access still fails
- External forwarding is blocked by policy
- Outlook web works but desktop Outlook remains broken
- The issue appears to affect multiple users
- There may be a wider Microsoft 365 service issue

## Skills Practised

- Outlook troubleshooting
- Microsoft 365 mailbox support
- Shared mailbox access review
- Email forwarding review
- Automatic replies support
- Mailbox storage review
- Service Desk ticket documentation
- IT Support workflow documentation

# Lab 02 — User Mailbox Settings Review

## Objective

The objective of this lab is to review common Outlook and mailbox settings used in Microsoft 365 support.

This lab focuses on mailbox permissions, email apps, email forwarding, automatic replies, and mailbox storage.

## Lab Environment

| Component | Details |
|---|---|
| Platform | Microsoft 365 Admin Centre |
| Section Used | Users > Active users > Mail |
| User Used | IT Support One |
| Role Practised | Entry-level IT Support / Service Desk technician |

## Tasks Completed

- Opened the IT Support One user account
- Reviewed mailbox storage
- Reviewed mailbox permissions
- Reviewed email apps
- Reviewed email forwarding settings
- Reviewed automatic replies settings
- Captured screenshots for documentation

## What I Learned

In this lab, I learned where to review important Outlook and mailbox settings in the Microsoft 365 Admin Centre.

I reviewed mailbox permissions, email apps, forwarding, automatic replies, and mailbox storage. These settings are useful when troubleshooting Outlook issues such as mailbox access problems, emails not sending or receiving, forwarding problems, or automatic replies not working.

## IT Support Relevance

Service Desk technicians commonly support users with Outlook and mailbox issues.

When a user reports an Outlook problem, checking mailbox settings can help confirm whether the issue is related to permissions, disabled email apps, forwarding rules, automatic replies, or storage.

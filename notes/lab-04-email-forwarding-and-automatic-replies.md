# Lab 04 — Email Forwarding and Automatic Replies

## Objective

The objective of this lab is to practise reviewing email forwarding and automatic reply settings for an Outlook mailbox.

This lab focuses on checking forwarding settings, confirming forwarding is disabled, configuring automatic replies temporarily, and turning automatic replies off again.

## Lab Environment

| Component | Details |
|---|---|
| Platform | Microsoft 365 Admin Centre |
| Section Used | Users > Active users > Mail |
| User Used | IT Support One |
| Role Practised | Entry-level IT Support / Service Desk technician |

## Tasks Completed

- Opened the IT Support One user account
- Reviewed email forwarding settings
- Confirmed email forwarding was disabled
- Reviewed Microsoft's warning about external forwarding
- Turned automatic replies on temporarily
- Added an automatic reply message
- Turned automatic replies off again
- Captured screenshots for documentation

## What I Learned

In this lab, I learned how to review email forwarding and automatic replies in the Microsoft 365 Admin Centre.

I also learned that email forwarding should be checked carefully because unexpected forwarding can affect email delivery and may create a security risk, especially if messages are forwarded externally.

Automatic replies are also a common Outlook support area because users may need help enabling, changing, or disabling out-of-office replies.

## IT Support Relevance

Service Desk technicians often support Outlook issues involving forwarding, automatic replies, mailbox access, and email delivery.

Checking these settings can help troubleshoot issues such as users not receiving emails, messages being redirected, or automatic replies not working as expected.

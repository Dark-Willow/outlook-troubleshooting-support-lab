# Lab 01 — Outlook Support Lab Setup

## Objective

The objective of this lab is to confirm access to Microsoft 365 mailbox support areas and Outlook on the web.

This lab focuses on reviewing user mailbox settings in the Microsoft 365 Admin Centre and confirming that the test user can access Outlook on the web.

## Lab Environment

| Component | Details |
|---|---|
| Platform | Microsoft 365 Admin Centre / Outlook on the web |
| User Used | IT Support One |
| Lab Focus | Outlook and mailbox support setup |
| Role Practised | Entry-level IT Support / Service Desk technician |

## Tasks Completed

- Opened Microsoft 365 Admin Centre
- Opened the IT Support One user account
- Reviewed the Mail tab for mailbox settings
- Confirmed mailbox storage, mailbox permissions, email apps, forwarding, and automatic replies areas
- Signed in to Outlook on the web
- Confirmed the mailbox opened successfully
- Captured screenshots for documentation

## What I Learned

In this lab, I learned where to review mailbox-related settings in the Microsoft 365 Admin Centre.

I also confirmed that Outlook on the web can be accessed by a test Microsoft 365 user.

This setup will be used for later labs involving shared mailbox access, email forwarding, automatic replies, mailbox permissions, email apps, and Outlook support scenarios.

## IT Support Relevance

Outlook support is common in Service Desk roles.

Users may report issues with mailbox access, shared mailboxes, emails not sending or receiving, automatic replies, forwarding, or Outlook sign-in. Knowing where to review these settings helps with first-line troubleshooting.

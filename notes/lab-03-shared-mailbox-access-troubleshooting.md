# Lab 03 — Shared Mailbox Access Troubleshooting

## Objective

The objective of this lab is to practise troubleshooting shared mailbox access in Outlook and Microsoft 365.

This lab focuses on reviewing shared mailbox settings, confirming shared mailbox membership, using Outlook on the web to open another mailbox, and confirming that the shared mailbox can be accessed.

## Lab Environment

| Component | Details |
|---|---|
| Platform | Microsoft 365 Admin Centre / Outlook on the web |
| Sections Used | Shared mailboxes, Outlook on the web |
| Shared Mailbox | IT Support Mailbox |
| User Used | IT Support One |
| Role Practised | Entry-level IT Support / Service Desk technician |

## Scenario

A user reports that they need access to the IT Support shared mailbox.

As the support technician, the task is to confirm that the shared mailbox exists, check the shared mailbox settings, confirm membership, and verify that the mailbox can be opened in Outlook on the web.

## Tasks Completed

- Opened the Shared mailboxes section in Microsoft 365 Admin Centre
- Confirmed that IT Support Mailbox exists
- Reviewed shared mailbox details
- Reviewed shared mailbox membership
- Opened Outlook on the web as the test user
- Used the Open another mailbox option
- Searched for IT Support Mailbox
- Opened the shared mailbox in Outlook
- Captured screenshots for documentation

## What I Learned

In this lab, I learned how to verify shared mailbox access from both the Microsoft 365 Admin Centre and Outlook on the web.

I reviewed the shared mailbox in the Admin Centre, checked the mailbox details and membership, then confirmed that the shared mailbox could be opened in Outlook.

This helped me understand how a Service Desk technician can investigate shared mailbox access issues.

## IT Support Relevance

Shared mailbox access issues are common in Service Desk roles.

Users may report that they cannot see a shared mailbox, cannot open it, or do not have the correct permissions. An IT Support technician should be able to check shared mailbox membership, mailbox permissions, and whether the mailbox can be opened in Outlook.

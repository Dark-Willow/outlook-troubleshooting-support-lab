# KB 02 — Shared Mailbox Not Showing

## Issue Summary

A user reports that they cannot see or open a shared mailbox in Outlook.

## Common Symptoms

- Shared mailbox does not appear in Outlook
- User cannot open the shared mailbox
- User receives an access denied message
- User can see the mailbox but cannot send or manage messages
- Shared mailbox appears in Outlook on the web but not in desktop Outlook

## Possible Causes

- User is not a member of the shared mailbox
- Mailbox permissions have not been applied yet
- Outlook has not refreshed
- User is signed into the wrong account
- Shared mailbox was recently created and has not fully synced
- Desktop Outlook profile issue

## Troubleshooting Steps

1. Confirm the shared mailbox name.
2. Confirm the affected user.
3. Open Microsoft 365 Admin Centre.
4. Go to Teams & groups > Shared mailboxes.
5. Open the shared mailbox.
6. Review members and permissions.
7. Confirm the user is listed as a member.
8. Ask the user to try Outlook on the web.
9. Use Open another mailbox in Outlook on the web.
10. If Outlook desktop is affected, ask the user to restart Outlook.
11. Escalate if permissions are correct but the mailbox still does not appear.

## Resolution Notes

Document whether the user was added to the shared mailbox, whether access worked in Outlook on the web, and whether further desktop Outlook troubleshooting was required.

## Skills Practised

- Shared mailbox access troubleshooting
- Mailbox membership review
- Outlook on the web support

- Service Desk documentation

# KB 05 — Mailbox Storage or Sync Issue

## Issue Summary

A user reports that Outlook is not syncing properly or that mailbox storage may be full.

## Common Symptoms

- New emails are not appearing
- Outlook is slow to update
- User cannot send or receive emails
- Mailbox storage warning appears
- Outlook on the web works but desktop Outlook does not
- Emails appear on one device but not another

## Possible Causes

- Mailbox storage is close to full
- Outlook desktop profile issue
- Internet connectivity issue
- Cached Outlook data issue
- Mailbox licence or access issue
- Email apps disabled
- Service issue or temporary Microsoft 365 delay

## Troubleshooting Steps

1. Confirm whether the issue affects Outlook desktop, Outlook web, or mobile.
2. Ask the user to test Outlook on the web.
3. Check mailbox storage in Microsoft 365 Admin Centre.
4. Review email apps to confirm access is allowed.
5. Confirm the user has a valid Microsoft 365 licence.
6. Ask the user to restart Outlook.
7. Check whether the issue affects only one device.
8. Escalate if Outlook web works but desktop Outlook continues to fail.

## Resolution Notes

Document whether the issue was related to mailbox storage, email apps, Outlook desktop, connectivity, or account access.

## Skills Practised

- Mailbox storage review

- Email apps review

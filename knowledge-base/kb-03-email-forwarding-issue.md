# KB 03 — Email Forwarding Issue

## Issue Summary

A user reports that emails are being forwarded unexpectedly or forwarding is not working as expected.

## Common Symptoms

- User is not receiving expected emails
- Emails are going to another mailbox
- Forwarding is enabled without the user expecting it
- Forwarded messages are not arriving
- User asks for forwarding to be enabled or disabled

## Possible Causes

- Forwarding enabled in Microsoft 365 Admin Centre
- Forwarding rule created in Outlook
- External forwarding restricted by policy
- Incorrect forwarding address
- User mailbox rule issue
- Security concern if messages are forwarded externally

## Troubleshooting Steps

1. Confirm the affected mailbox.
2. Open the user in Microsoft 365 Admin Centre.
3. Go to the Mail tab.
4. Open Manage email forwarding.
5. Confirm whether forwarding is enabled or disabled.
6. Check whether the forwarding address is internal or external.
7. Disable forwarding if it is not required.
8. Ask the user to check Outlook rules if forwarding is not visible in Admin Centre.
9. Escalate if external forwarding is required but blocked by policy.

## Resolution Notes

Document whether forwarding was enabled, disabled, or left unchanged. Include whether the forwarding address was internal or external.

## Skills Practised

- Email forwarding review
- Mailbox settings review
- Outlook support awareness
- Security awareness
- IT Support documentation

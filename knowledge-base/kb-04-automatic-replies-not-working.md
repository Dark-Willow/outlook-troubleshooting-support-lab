# KB 04 — Automatic Replies Not Working

## Issue Summary

A user reports that automatic replies or out-of-office messages are not working.

## Common Symptoms

- Automatic replies are not being sent
- Internal replies work but external replies do not
- User cannot find automatic reply settings
- Old out-of-office message is still active
- Automatic replies are enabled but message text is incorrect

## Possible Causes

- Automatic replies are turned off
- Reply message is missing or incorrect
- External replies are not enabled
- User configured replies in the wrong mailbox
- Shared mailbox automatic replies need to be checked separately
- Browser or Outlook settings issue

## Troubleshooting Steps

1. Confirm whether the issue affects a user mailbox or shared mailbox.
2. Open the mailbox settings in Microsoft 365 Admin Centre.
3. Go to Manage automatic replies.
4. Confirm whether automatic replies are turned on.
5. Check the internal reply message.
6. Check whether external replies are enabled if needed.
7. Update the message if required.
8. Save changes.
9. Ask the user to test again.

## Resolution Notes

Document whether automatic replies were enabled, updated, disabled, or confirmed as already configured correctly.

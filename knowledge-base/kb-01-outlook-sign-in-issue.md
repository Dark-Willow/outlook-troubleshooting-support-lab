# KB 01 — Outlook Sign-in Issue

## Issue Summary

A user reports that they cannot sign in to Outlook or Outlook on the web.

## Common Symptoms

- User cannot access Outlook
- User receives an incorrect password message
- Outlook keeps asking for a password
- User can access other services but not Outlook
- User account may be blocked or password may need resetting

## Possible Causes

- Incorrect password
- Password expired or reset required
- Sign-in blocked
- Licence not assigned
- Account not fully set up
- Browser cache or session issue
- MFA or authentication issue

## Troubleshooting Steps

1. Confirm the affected username.
2. Check the user account in Microsoft 365 Admin Centre.
3. Confirm the user has an active Microsoft 365 licence.
4. Check whether sign-in is blocked.
5. Reset the user password if required.
6. Ask the user to try signing in again.
7. Test Outlook on the web.
8. Ask the user to clear browser cache or try another browser if needed.
9. Escalate if the issue continues after account checks.

## Resolution Notes

Document whether the issue was resolved by resetting the password, unblocking sign-in, confirming the licence, or advising the user to retry Outlook access.

## Skills Practised

- Outlook sign-in troubleshooting
- Password reset awareness
- Sign-in status review
- Licence check
- User support documentation

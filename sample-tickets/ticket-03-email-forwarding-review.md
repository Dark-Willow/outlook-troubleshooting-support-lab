# Ticket 03 — Email Forwarding Review

## Ticket Summary

User reports possible email forwarding issue.

## User / Requester

IT Support One

## Issue Type

Incident

## Priority

Medium

## Scenario

The user reports that emails may not be arriving as expected. Email forwarding needs to be reviewed.

## Troubleshooting / Support Actions

- Opened the user account in Microsoft 365 Admin Centre
- Opened the Mail tab
- Reviewed Manage email forwarding
- Confirmed forwarding was not enabled
- Reviewed Microsoft warning about external forwarding
- Documented the result

## Resolution

Email forwarding was reviewed and confirmed as disabled.

## Skills Practised

- Email forwarding review
- Outlook mailbox support
- Security awareness
- IT Support documentation

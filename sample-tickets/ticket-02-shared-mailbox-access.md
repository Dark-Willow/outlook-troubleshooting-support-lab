# Ticket 02 — Shared Mailbox Access

## Ticket Summary

User needs access to the IT Support shared mailbox.

## User / Requester

IT Support One

## Issue Type

Service Request

## Priority

Medium

## Scenario

The user needs to access the IT Support shared mailbox in Outlook on the web.

## Troubleshooting / Support Actions

- Confirmed the shared mailbox exists in Microsoft 365 Admin Centre
- Reviewed shared mailbox details
- Reviewed shared mailbox membership
- Used Outlook on the web
- Used Open another mailbox
- Searched for IT Support Mailbox
- Confirmed the shared mailbox opened successfully

## Resolution

The shared mailbox was opened successfully in Outlook on the web.

- Shared mailbox access troubleshooting
- Outlook on the web support

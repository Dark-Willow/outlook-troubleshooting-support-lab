# Ticket 01 — Outlook Sign-in Issue

## Ticket Summary

User cannot sign in to Outlook.

## User / Requester

IT Support One

## Issue Type

Incident

## Priority

High

## Scenario

The user reports that they cannot sign in to Outlook on the web. The issue may be related to password, sign-in status, licence assignment, or browser session problems.

## Troubleshooting / Support Actions

- Confirmed the affected user account
- Checked the user in Microsoft 365 Admin Centre
- Reviewed sign-in status
- Confirmed mailbox and mail settings were available
- Confirmed Outlook on the web access
- Reviewed possible password or browser session issue
- Documented findings

## Resolution

Outlook on the web access was confirmed. Further troubleshooting would depend on the exact sign-in error reported by the user.

## Skills Practised

- Outlook sign-in troubleshooting
- User account review
- Microsoft 365 mailbox support
- Service Desk documentation

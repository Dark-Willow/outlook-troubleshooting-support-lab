# Ticket 05 — Mailbox Storage or Sync Issue

## Ticket Summary

User reports mailbox sync or storage issue.

## User / Requester

IT Support One

## Issue Type

Incident

## Priority

Medium

## Scenario

The user reports that Outlook is not syncing correctly or that emails are not updating as expected.

## Troubleshooting / Support Actions

- Opened the user mailbox settings
- Reviewed mailbox storage
- Reviewed mailbox permissions
- Reviewed email apps
- Reviewed forwarding settings
- Confirmed Outlook on the web access
- Documented possible next steps for Outlook desktop troubleshooting

## Resolution

Mailbox settings and Outlook web access were reviewed. Further troubleshooting would depend on whether the issue affects Outlook web, desktop Outlook, or mobile Outlook.

## Skills Practised

- Mailbox storage review
- Outlook sync troubleshooting
- Email apps review
- User mailbox support
- IT Support documentation

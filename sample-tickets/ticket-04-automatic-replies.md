# Ticket 04 — Automatic Replies

## Ticket Summary

User needs automatic replies configured and then disabled.

## User / Requester

IT Support One

## Issue Type

Service Request

## Priority

Low

## Scenario

The user needs an automatic reply message configured temporarily for unavailable status.

## Troubleshooting / Support Actions

- Opened the user account in Microsoft 365 Admin Centre
- Opened the Mail tab
- Opened Manage automatic replies
- Enabled automatic replies temporarily
- Added an automatic reply message
- Confirmed automatic replies were configured
- Disabled automatic replies after testing
- Documented the result

## Resolution

Automatic replies were configured temporarily and then disabled after testing.

- Automatic replies configuration
- Out-of-office support
- Outlook mailbox support
- Service Desk documentation
